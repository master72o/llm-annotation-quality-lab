# Quality Lab Figures Directory

This directory stores visual analytics generated by the annotation quality research lab:

- `before_vs_after_agreement.png`: Bar chart comparing Before vs After guideline metrics for Fleiss' Kappa ($\kappa$), Krippendorff's Alpha ($\alpha$), and Raw Agreement.
- `disagreement_by_category.png`: Category-specific disagreement frequency breakdown.
- `ground_truth_accuracy.png`: Bar chart comparing annotator accuracy against ground truth benchmark before vs after guidelines.
